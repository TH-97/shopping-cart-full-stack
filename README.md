## 요구사항 정리

## 주문 확인 페이지 진입 시

- 선택한 상품의 정보를 조회 후 출력한다.
- 주문 정보를 조회 후 출력한다.
- 새로고침 시 기존 정보가 유지된다.
- 주문 금액이 100,000원 이상이면 무료 배송

## 쿠폰 적용 클릭 시

- 쿠폰 선택 모달이 뜬다.
- 내가 가진 쿠폰 목록을 조회 후 출력한다.
- 사용할 수 없는 쿠폰은 비활성화 된다.
- 쿠폰을 지정하지 않았다면, 최고 할인 금액으로 자동 선택된다.
- 쿠폰은 최대 2개까지 선택 가능하다.
- 정액 쿠폰과 정률 쿠폰 동시 선택 시, 정액 쿠폰이 우선 적용된다.
- 쿠폰을 선택하면, 선택된 쿠폰의 누적 쿠폰 할인 금액이 계산된다.
- 취소 버튼 클릭 시, 선택한 쿠폰이 적용되지 않는다.
- 쿠폰 사용하기 버튼 클릭 시, 쿠폰이 적용된다.

## 제주도 및 도서 산간 지역 토글 클릭 시

- 활성화 시, 배송비가 3000원이 추가된다.
- 활성화 시, 배송비 관련 쿠폰이 선택되어 있다면, 쿠폰 할인 금액도 변경된다.

## 결제하기 클릭 시

- 총 결제 금액과 주문 내역이 표시된다.
