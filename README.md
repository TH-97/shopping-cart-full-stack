# 장바구니 풀스택 미션

# 구현 가이드

### 1. 한 파일에 다 구현 (동작하는 MVP)

- header / cartItemList / 금액 표시 / 주문 확인 버튼
- 선택 상태 (진입 시 전체 선택 디폴트)
- 파생 상태: 결제 금액, 배송비(10만원↑ 무료)
- 수량 변경(최대 99), 상품 제거
  - 상태·로직·뷰가 한 파일에 섞여 있어도 OK

### 2. 서버 연동 & 영속화

- data fetching hook 직접 구현 (data / loading / error)
- 로딩 / 에러 UI
- 선택 상태 새로고침에도 유지 (영속화)

### 3. 테스트 (input → output)

- 비동기는 MSW

### 4. 리팩토링

- 컴포넌트 / 비즈니스 로직 분리
- props 인터페이스 다듬기 (DIP)
